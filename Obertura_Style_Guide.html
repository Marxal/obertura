Spacing scale

One 4-based scale — 4 / 8 / 12 / 16 / 24 — drives every gap and padding from v1.2 on, so screens stop inventing their own numbers. Tokens: --space-xs … --space-xl.

xs · 4
sm · 8
md · 12
lg · 16
xl · 24

Components

Shared building blocks layered on the tokens. Screens compose these instead of hand-rolling paddings. .section — a soft wrapper (hairline border + a very faint fill + a title row) — is what kills the “stacked” feeling. .card is the one card; .row the standard list row.

Buttons

One shared chrome, five variants. Primary (oxblood) shows a subtle top-light vertical gradient in light mode only — dark stays flat. Success is sage and danger is brick, the same two colours used for the drill’s right / wrong feedback.

Theme behaviour

The active theme defaults to the system preference and can be pinned to light, dark, or auto. The choice is saved in localStorage under obertura-theme. JS resolves the choice and sets data-theme="light|dark" on <html>; CSS only ever reads data-theme. See src/theme.ts.
