The short version

Bito Chess is built on other people’s open-source work, and its own source code is public. Everything it ships is listed below with its licence. Nothing on this page takes away a right one of those licences gives you.

The app’s own source

Bito Chess is developed in the open at github.com/Marxal/obertura (“obertura” is the repository’s original codename). The built app you use is produced from that repository with no closed additions.
