# **Bito Chess – Catalan Localization & Tone of Voice Guide**

**Purpose:** Make Bito Chess sound like an app originally designed in Catalan, rather than a translation from English or Spanish.

## **1\. Bito's voice and personality**

Bito should sound like a knowledgeable, friendly chess-training companion.

The tone should be:

* **Natural:** Use contemporary, idiomatic Catalan.  
* **Informal:** Always address the player using *tu*.  
* **Direct:** Short sentences and clear instructions.  
* **Encouraging:** Motivate without exaggerating.  
* **Confident:** Know the subject without sounding pretentious.  
* **Friendly:** Never aggressive, childish or overly enthusiastic.

Bito is not a traditional chess teacher constantly giving instructions. It is a training companion that helps players improve at their own pace.

### **The golden rule**

If a sentence sounds like something translated from English or Spanish, rewrite it from scratch in Catalan.

## **2\. Addressing the player**

Always use the informal second-person singular.

Use:

* Juga  
* Mostra  
* Continua  
* Revisa  
* Tria  
* Millora  
* Recupera  
* Recorda

Avoid:

* Vostè  
* Vosaltres (when addressing an individual)  
* Formal constructions  
* Unnecessary passive voice

### **Gender**

Avoid gendered expressions when possible.

Prefer:

* Et donem la benvinguda.  
* Comencem?  
* Ja ho tens\!  
* Has completat el repte.  
* Has superat el repte.

Avoid:

* Benvingut\!  
* Estàs preparat?  
* Expressions that unnecessarily assume the player's gender.

### **Important terminology decisions**

**Jugada vs. moviment**

Use *jugada* when referring to a chess move. Reserve *moviment* for physical movement or more general contexts.

**Partida vs. joc**

Use *partida* when referring to a chess game.

**Variant vs. variació**

Use *variant* when referring to an opening variation.

**Línia vs. variant**

They are not interchangeable. A line is a sequence of moves; a variation is a particular branch or development of an opening.

**Badada i Cagada**

The only extra fun tone in catalan, to give extra personality will be to call blunder a “cagada” and a mistake a “badada”

* Badada: a mistake.  
* Errada greu: a serious mistake or blunder. We’ll call it “Cagada” it will be the only extra fun touch of the app.

**Problema vs. exercici**

* Problema, problemes: a chess puzzle or tactical problem. Not *trencaclosques*.  
* Exercici: a training activity.

**Repàs vs. revisió**

Prefer *repàs* when referring to reviewing opening lines or training material.

## **7\. Avoid Spanish calques and unnatural expressions**

Catalan software translations often inherit structures from Spanish or English.

Pay particular attention to these expressions.

| Avoid | Prefer |
| ----- | ----- |
| Realitzar una jugada | Fer una jugada |
| Donar clic | Fer clic / Prémer |
| En aquest moment | Ara / Ara mateix |
| A nivell de | Pel que fa a / En |
| En base a | A partir de / Basant-se en |
| Jugar un moviment | Fer una jugada |
| Introdueix el teu nom | Escriu el teu nom |
| No hi ha cap problema | Cap problema |
| Efectuar una acció | Fer una acció |
| Procedir amb el procés | Continuar |

These are general guidelines, not absolute prohibitions. Context always matters.

## **8\. Avoid overly formal software language**

Bito should not sound like an administrative website.

| Too formal or robotic | More natural |
| ----- | ----- |
| S'ha completat correctament | Fet\! |
| S'ha produït un error | Alguna cosa ha fallat |
| No s'han trobat resultats | No hem trobat cap resultat |
| Selecciona una opció | Tria una opció |
| Introdueix les dades | Escriu les dades |
| Continua amb el procés | Continua |
| Accedeix al teu compte | Inicia sessió |
| El teu progrés ha estat desat | Hem desat el teu progrés |

Do not make every message excessively casual either. Use exclamation marks only when they genuinely add something.

## **9\. Expressions that translate differently**

Do not translate English expressions word for word.

| English | Natural Catalan |
| ----- | ----- |
| Keep going | Continua\! / Som-hi\! |
| You're all set | Ja ho tens\! |
| Let's go | Som-hi\! |
| Well done | Molt bé\! |
| Try again | Torna-hi\! |
| Coming up next | A continuació |
| You're on a streak | Estàs en ratxa\! |

Sometimes a completely different expression is the best translation.

## **10\. Writing and punctuation rules**

Apply these principles consistently.

* Prefer short sentences.  
* Use natural Catalan word order.  
* Avoid unnecessary passive constructions.  
* Use the imperative when giving instructions.  
* Avoid excessive exclamation marks.  
* Use consistent terminology across the entire application.  
* Avoid unnecessary repetition of words such as *escacs*, *obertura* and *partida* when the context is already clear.  
* Use accents and apostrophes correctly.  
* Use Catalan typography and punctuation conventions.  
* Avoid mixing formal and informal address.

## **11\. Things to avoid: final checklist**

* Don't use *vosaltres* when addressing an individual.  
* Don't use Spanish vocabulary just because it looks similar.  
* Don't translate every English expression literally.  
* Don't use *moviment* everywhere when *jugada* is more appropriate.  
* Don't overuse *realitzar*, *efectuar* or *procedir*.  
* Don't use unnecessary exclamation marks.  
* Don't mix *tu* and *vostè*.  
* Don't alternate between *desar* and *guardar* without a reason.  
* Don't mix *iniciar sessió* and *accedir al compte* unnecessarily.  
* Don't use long sentences when a short expression works.  
* Don't force chess jargon where ordinary language is clearer.  
* Don't make Bito sound like a formal teacher or a robotic translation.

## **12\. Quality control process**

Every new Catalan text should pass three checks.

**1\. Terminology**

Is this the correct word in Catalan chess?

**2\. Naturalness**

Would a Catalan speaker actually say this?

**3\. User experience**

Is this the shortest, clearest expression that communicates the meaning?

Whenever possible, ask Catalan chess players to test the interface. A regular chess player can often identify unnatural chess terminology that a conventional translator might overlook.
